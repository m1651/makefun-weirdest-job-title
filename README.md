# Weirdest Job Title: Blind Judge Showdown

A make.fun bounty entry. `main.py` (Python 3, stdlib only, no network) writes
a single original job title — a real-sounding job with one hilariously
specific twist — to `/output/entry.txt`:

> Senior Taste-Tester of Gas Station Sushi

The title is 40 characters, deterministic, and validated before writing
(non-empty, single line, within the 60-character limit).
